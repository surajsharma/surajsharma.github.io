# [evenzero](https://evenzero.in)

[![Deploy to GitHub Pages](https://github.com/surajsharma/surajsharma.github.io/actions/workflows/deploy.yaml/badge.svg?branch=main)](https://github.com/surajsharma/surajsharma.github.io/actions/workflows/deploy.yaml)

Projects and Experiments are paginated in individual level-two sections using
Webcore UI's Astro Pagination component. Their Markdown remains the source of
truth, and all sections remain accessible without JavaScript. Table-of-contents
fragment links open the page containing the requested section. Webcore's global
setup/reset is intentionally not included, so the site's existing fonts and
light/dark theme continue to apply.
